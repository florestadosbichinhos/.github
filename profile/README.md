# Floresta dos Bichinhos 🌳

Jogo educativo, gratuito e de código aberto para crianças de 3 a 7 anos. Brincadeiras de
cores, números, letras, memória e coordenação com a Didia, a Lali, o Lolo e a Sophy.

Sem anúncios, sem compras, sem coleta de dados e funciona sem internet.

- 🎮 **Site e downloads:** [florestadosbichinhos.github.io](https://florestadosbichinhos.github.io)
- 🧩 **Código do jogo:** [floresta-dos-bichinhos](https://github.com/lucassdoro/floresta-dos-bichinhos) (Godot 4)
- 🌐 **Código do site:** [florestadosbichinhos.github.io](https://github.com/florestadosbichinhos/florestadosbichinhos.github.io)

## Quer ajudar?

Toda ajuda é bem-vinda: programar, desenhar, gravar vozes, traduzir, revisar o lado
pedagógico ou testar com uma criança e contar como foi. Não precisa saber programar.

Todo trabalho começa por uma issue, e tudo passa por curadoria para ser bom para os
pequenos. Veja o [guia de contribuição](https://github.com/lucassdoro/floresta-dos-bichinhos/blob/main/CONTRIBUTING.md).
